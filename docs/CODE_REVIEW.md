# Ревью перед публичной публикацией

Дата: 18 октября 2026. Проверены Python API, индексатор, SQLite, импорт оценок, Windows-интеграция, React-интерфейс, конфигурация и сценарий установки IIS. Это прикладное ревью с исправлениями и регрессионными проверками; оно не является доказательством отсутствия любых дефектов.

Дополнительно транзитивный esbuild закреплён через pnpm override на 0.28.1, устраняя предупреждение GHSA-g7r4-m6w7-qqqr для его Windows dev-сервера. Приложение не использует режим esbuild serve; совместимость override проверена сборкой Vite.

Для публикации добавлены `.gitignore`, проверка Git index, пример конфигурации, документация, лицензия и CI. Музыкальные файлы, SQLite, личные заметки, кеш источника, реальные пути и Windows-ярлыки в репозиторий не входят.

## Регрессионные проверки

Изолированный набор содержит **41 тест**. Он создаёт временный двухфайловый архив, подменяет источник и Windows-запуск. На данном Windows-ПК 40 тестов прошли, один пропущен: создание символической ссылки требует дополнительных прав или режима разработчика. Этот тест может выполняться в Ubuntu CI. Сетевые ответы в тестах синтетические; личная база не используется.

Проверки охватывают индексирование и повторный обход, отдельные версии, исчезновение и замену файлов, сохранение личных данных, фильтры, безопасные пути, импорт/экспорт, парсер и точное сопоставление оценок, ошибки/повторы, маркер продолжения, Windows-ассоциации и изолированный HTTP API с Host/Origin/CSRF.

Сборка интерфейса и аудит зависимостей запускаются отдельно. Реальное открытие партитур в Guitar Pro до этого проверялось в работающем и полностью закрытом приложении; автоматические тесты текущего helper проверяют выбранный механизм запуска, но не состояние GUI. Результаты облачного CI следует смотреть во вкладке Actions конкретного коммита.

В обновлённой сборке на IIS вручную подтверждены поиск «кино группа крови», сброс формата и сортировка по времени при переходе в «Недавние», сохранение фокуса при фоновом опросе, закрытие настроек по Escape. На ширине 390 px горизонтального переполнения страницы нет; консоль браузера не содержит ошибок или предупреждений. Скриншоты каталога в `docs/screenshots/` сняты с этой сборки и не содержат личных путей или заметок.

Первый запуск CI также выявил зависимость одного тестового сравнения от Windows-представления временной папки: краткий путь 8.3 и полный путь указывали на один файл. Ожидаемый путь в тесте теперь канонизируется через `resolve()`, как и путь из API; сама проверка выхода за пределы архива сохранена.

## Известные ограничения

- Поддерживается структура архива `bucket/artist/file`. Восстановление названий добавлено после этого ревью; оно читает ограниченный заголовок GP3/4/5, без анализа нот и дорожек. См. [проверку названий](NAME_MATCHING.md).
- Парсер зависит от HTML источника и показывает доступные звёзды. Нет гарантии оценок для всех файлов или немедленного удаления устаревшей оценки с неполной страницы.
- Нет контентного хеширования всего архива; изменение с сохранением размера и mtime не обнаруживается.
- Нет многопользовательской авторизации и публичного API; развёртывание рассчитано на loopback и интерактивного пользователя Windows.
- Автоматическое тестирование GUI Guitar Pro и модификации системной конфигурации IIS в CI не выполняются. Их проверяют на целевом ПК.
